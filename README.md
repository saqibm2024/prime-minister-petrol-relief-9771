# Prime Minister Petrol Relief Scheme 2026

## 9771 Petrol Relief Registration Guide

This project provides information about the Prime Minister Special Relief Scheme and the 9771 petrol relief registration process.

The guide explains how eligible citizens can register through SMS, obtain a petrol relief token, and use the token to receive subsidized petrol.

## Key Information

* Registration Number: **9771**
* Registration Keyword: **REG**
* Token Keyword: **TOK**
* Petrol Relief: **Rs. 100 per liter**
* Motorcycle and Three-Wheeler Quota: **5 liters**
* Car Quota: **10 liters**
* Car Engine Capacity: **Up to 800cc**
* Registration Date Format: **DDMMYYYY**
* Citizen Helpline: **9771**
* Petrol Pump Helpline: **9772**

## 9771 SMS Registration

Eligible applicants can register through SMS by using the following format:

```text
REG <CNIC> <Plate No> <Province Code> <Registration Date>
```

The SMS should be sent to:

```text
9771
```

The registration date should be entered in **DDMMYYYY** format.

Example:

```text
02092026
```

## How to Get the Petrol Token

After successful registration, eligible applicants can request their petrol relief token by sending:

```text
TOK
```

to:

```text
9771
```

The token can then be presented at the petrol pump for verification.

## Eligibility

### Motorcycles and Three-Wheelers

Eligible motorcycles and three-wheelers should have been registered on or after **January 1, 2011**.

According to the provided scheme information, motorcycles and three-wheelers do not necessarily have to be registered in the applicant's own name.

### Cars Up to 800cc

Eligible cars must:

* Have an engine capacity of up to **800cc**
* Be registered on or after **January 1, 2006**
* Be registered in the applicant's own name

The applicant must also use a mobile number registered against their own CNIC.
